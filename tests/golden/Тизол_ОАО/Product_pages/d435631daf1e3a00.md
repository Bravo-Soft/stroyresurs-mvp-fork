# Изоспан ML proff

Усиленная односторонняя клейкая лента

Ширина - 50 мм

Длина - 25 м.п.

Усиленная односторонняя клейкая лента. Лента Изоспан ML proff предназначена для склеивания между собой полотнищ материалов Изоспан с целью герметизации нахлёстов, а также для герметизации примыканий полотнищ материалов Изоспан к другим элементам кровли, стен, перекрытий.
