# Изоспан KL+

Усиленная двухсторонняя клейкая лента

Ширина - 25 мм

Длина - 25 м.п.

Усиленная двухсторонняя клейкая лента. Предназначена для склеивания между собой полотнищ материалов Изоспан с целью герметизации нахлёстов, а также для герметизации примыканий полотнищ материалов Изоспан к элементам кровли, стен, перекрытий.
