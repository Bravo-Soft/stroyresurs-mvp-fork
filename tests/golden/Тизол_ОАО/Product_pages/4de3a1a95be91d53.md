# Изоспан SL

Бутил-каучуковая соединительная лента

Ширина - 15 мм

Длина - 45 м.п.

Толщина - 1 мм

## Уникальные свойства

* Используется для склеивания между собой полотнищ пароизоляции Изоспан
* Используется для крепления полотнищ пароизоляции Изоспан к шероховатым поверхностям (строительный камень, дерево)

Лента Изоспан SL предназначена для склеивания между собой полотнищ пароизоляции Изоспан с целью герметизации нахлёстов, а также для крепления полотнищ пароизоляции Изоспан к шероховатым поверхностям (строительный камень, дерево).
