# Изоспан FL termo

Клейкая алюминиевая лента

Ширина - 50 мм

Длина - 40 м.п.

Клейкая алюминиевая лента. Лента  Изоспан FL termo предназначена для соединения между собой полотнищ материала Изоспан FB, а также Изоспан FS, FD, RF, FX.

## ХАРАКТЕРИСТИКИ

| Ширина | 50 мм |
| --- | --- |
| Длина | 40 м.п. |
| Защитный слой | силиконизированная бумага |
| Состав | алюминиевая фольга с клеевым слоем |
| Усилие на разрыв | 200 Н/25 мм |
| Растяжение до разрыва | 6 % |
| Клейкость к стали | 3,8 Н/25 мм |
| Температурная устойчивость | от -40 C до +180 C |
| Температура монтажа | не ниже +5 C |

## ПРИМЕНЕНИЕ

Применяется для соединения между собой полотнищ материала Изоспан FB, а также Изоспан FS, FD, RF, FX.
